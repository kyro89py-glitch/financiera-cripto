# Financiera Cripto: demostración en Codespaces

La financiera se instala y se inicia sola. En unos segundos se abre en una pestaña nueva del navegador.

**Si no se abrió:** abajo, en la pestaña **PUERTOS** (o *PORTS*), busca el puerto **5000** y toca el ícono del globo.

## Cuentas de prueba

Todas usan la contraseña `Demo-2026!`

| Cuenta | Qué ves |
|---|---|
| `admin@demo.local` | Todo el panel del equipo y los ajustes |
| `operaciones@demo.local` | Aprobar aportes y retiros, dar de alta clientes |
| `cumplimiento@demo.local` | Segunda firma, documentos, conciliación y bitácora |
| `lucia@demo.local` | El portal de un cliente |

## Para tener en cuenta

- Los datos son de demostración y se guardan solo en este Codespace.
- Las compras y ventas se hacen en el **simulador**: no se usa dinero real ni se conecta a Binance.
- El Codespace se apaga solo después de un rato sin uso. Para volver, entra en github.com/codespaces y ábrelo de nuevo.
